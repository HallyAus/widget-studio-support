Widget Studio
for Home Assistant

Custom widgets, everyday controls and clear readings for your Home Assistant home. Free, with no ads, analytics or subscription.

This independent app is being prepared for internal testing. An App Store download is not available yet.

Getting connected

Tap Find Home Assistant on Wi-Fi, or enter your server URL, then choose Sign in with Home Assistant. You sign in through the system browser directly to your home; the app never reads your password. Credentials stay in the iPhone Keychain and refresh automatically. An access-token option remains available under Advanced. Use HTTPS for remote access; local HTTP is supported only on trusted private networks.

Adding a widget

Save a layout in the app. Hold your iPhone Home Screen, choose Edit → Add Widget, and search for Widget Studio. Hold the added widget → Edit Widget to choose your saved layout. For Lock Screen widgets, hold the Lock Screen → Customise → Lock Screen, then select Widget Studio in the widget area.

Appearance and bin collection

Choose System, Light or Dark in Settings. Each widget layout also has an appearance choice. The Bin collection template supports date sensors, Waste Collection Schedule attributes and Home Assistant calendars. Select a source for each bin, choose its label, icon and lid colour, and filter shared events by waste type. Dates are read from your Home Assistant setup; this app does not provide council collection data. Unknown dates and saved schedules are labelled.

Updates and connection issues

iOS controls widget refresh timing. Widgets show the last update and label saved readings. Open the app to refresh and check connectivity. Remote access needs a working HTTPS address or VPN. Saved charts stay visible when a refresh fails, the server is offline, or a sensor is unavailable. Choose Bar, Line, Area, Auto or state/availability timelines. Missing data is never filled with zero. Recorder must be enabled for history. Pair separately authenticated local and remote addresses for Auto, Local only or Remote only routing; the app does not provide a relay.

Advanced widget workflows

Build comparison charts, household briefings with reasons, and visual rules for labels, icons and colours. Preview difficult conditions before saving. Share anonymised recipes and map compatible sources on import. Connection history and private action receipts explain saved readings and distinguish accepted commands from states reported by HA. Commands are never queued offline or replayed on reconnect. iOS widget rendering and refresh remain system-controlled.

Get support

Report an issue or request a feature. Include your iOS version, app version and a description of the issue. Please do not include access tokens, passwords, private server URLs, location data or unredacted screenshots of your home.
